# Exemplar files

The ALFWorld and ScienceWorld files are copied byte-for-byte from the baseline harness
they belong to, and the Plancraft file is generated from the authors' prompt builders. All
are loaded as data, outside the prompt fingerprint; `run.json` records their sha256.

## `alfworld_react_prompts.json`

`prompts/alfworld_3prompts.current-grammar.json` from the ReAct probe: the ReAct
repository's `prompts/alfworld_3prompts.json` (github.com/ysymyth/ReAct @ `6bdb3a1`) with
its placement verb rewritten to the grammar ALFWorld 0.5.0 ships (`put X in/on Y` ->
`move X to Y`, and the matching feedback line); every other line is byte-identical to the
original. The ReAct repository is MIT-licensed:

## `scienceworld_react_prompts.json`

`baselines/ReAct_baseline/prompt.jsonl` from SwiftSage (github.com/SwiftSage/SwiftSage,
branch `science_world` @ `b8ea624`): the ReAct baseline's one-shot exemplar per task type,
`think:` turns included. The parity runner uses it as is; the solver strips the `think:`
turns at load time, which yields the repository's own `prompt_no_think.jsonl` exactly. The
pinned commit ships no license file; the repository is published under the MIT license on
its main branch.

## `plancraft_react_prompts.json`

Generated by `scripts/setup/build_plancraft_prompts.py` from Plancraft
(github.com/gautierdag/plancraft @ `7617e9f`), `plancraft/environment/prompts.py`:
`system` is `get_system_prompt` and `fewshot` is `get_prompt_example` written as a
`> command` transcript, both over the handlers move, smelt, search and impossible, with
`random.seed(42)` before each `gold_search_recipe` call. `plancraft.manifest.json` is built
by `scripts/setup/build_plancraft_manifest.py` from the same repository's
`plancraft/data/{train,test}.json`. The Plancraft repository is MIT-licensed, Copyright (c)
2024 Gautier Dagan, under the same terms as the ReAct license above.
